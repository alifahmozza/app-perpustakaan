# Skenario Demo Aplikasi Perpustakaan

1. **Login:** Membuka halaman login dan masuk menggunakan kredensial admin.
2. **Tampilkan Dashboard:** Menunjukkan ringkasan statistik (jumlah buku, anggota, dll).
3. **Tambah Kategori:** Mencontohkan pembuatan kategori buku baru.
4. **Tambah Buku:** Mengisi form untuk menambahkan buku baru ke dalam kategori tersebut.
5. **Tambah Anggota:** Mendaftarkan data anggota perpustakaan baru.
6. **Buat Peminjaman:** Membuat transaksi peminjaman buku oleh anggota.
7. **Lihat Daftar Peminjaman Aktif:** Mengecek status buku yang sedang "dipinjam".
8. **Proses Pengembalian:** Mengubah status peminjaman menjadi "dikembalikan".
9. **Tampilkan Laporan:** Melihat hasil rekapitulasi data.
10. **Demo API:** Menunjukkan pengujian endpoint menggunakan Postman / Thunder Client.
